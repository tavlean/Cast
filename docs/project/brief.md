# Cast brief

**What it is.** A shadow stack generator: compose, compare, and export expressive CSS and Tailwind shadow systems.

**Where it stands (2026-11-19).** A minimal SvelteKit 3 scaffold with one placeholder page. No generator features exist yet. Status in project.json is `planned`.

**Stack.** SvelteKit 3, Svelte 5 runes, Vite 8, TypeScript, pnpm. `adapter-auto` is still the adapter because no host is chosen.
