## Docs discipline

Read the docs related to your task before working, and update the ones you invalidated during or right after it; a task is not done while a doc it touched is stale. One topic per doc, one source of truth per topic, absolute dates, and only what a capable reader could not guess, with the reason. Add every new doc to this index in the same change.
