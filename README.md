# Cast

Cast is a SvelteKit foundation for a shadow stack generator: compose, compare, and export expressive CSS and Tailwind shadow systems.

Docs start at [docs/README.md](docs/README.md).

## Developing

```sh
pnpm install
pnpm run dev
```

`pnpm run check` type-checks, `pnpm run build` builds, and `pnpm run preview` serves the build.
